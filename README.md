## ✨ 项目简介

“湘中标书 Skills”是面向中文及中英双语招投标场景设计的一组 Codex Skills，围绕投标工作的三个关键环节，将复杂的招标文件处理为可执行、可核验、可复用的工作成果。

它不替代企业的专业判断，而是把招标文件中的要求、评分点、证据和风险组织起来，帮助团队减少遗漏，提升编标效率与交付质量。

## 🧭 一套流程，三个协同 Skill

```mermaid
flowchart LR
    A[📥 招标文件与企业资料] --> B[🔎 智能标书分析]
    B --> C[🧩 评分响应编制]
    C --> D[🛡️ 提交前智能审查]
    D --> E[📄 可追溯投标成果]
```

| Skill | 解决的问题 | 主要输出 |
| --- | --- | --- |
| 🔍 **智能标书分析** | 招标文件要求分散、重点难以快速定位 | 要求清单、资格审查表、交付物清单、时间节点与风险提示 |
| 🧩 **评分响应编制** | 评分条款与企业证据难以一一对应 | 评分响应矩阵、证据索引、章节写作提纲与响应初稿 |
| 🛡️ **智能标书审查** | 定稿前容易出现漏项、错项和证据链断点 | 合规审查清单、评分覆盖检查、证据链检查、风险分级与整改建议 |

## 🎯 核心价值

- **要求可追溯**：将每一项结论回链到招标文件条款、页码或企业证据。
- **评分可对照**：把评分标准转化为“评分点—响应内容—证明材料—文件位置”的闭环。
- **风险可分级**：区分资格性、符合性、评分性和提交性风险，优先处理可能导致废标的问题。
- **协作可复用**：统一分析、编写和审查口径，便于销售、技术、商务与管理人员协同工作。
- **结果可交付**：输出结构化清单、矩阵、提纲和审查报告，支持后续人工复核与归档。

🏢 中小企业投标团队　·　📋 政府采购及项目投标人员　·　💼 商务与销售人员　·　🧑‍💻 标书编制与项目管理人员

## 🚀 快速开始

1. 选择与当前任务对应的 Skill 文件夹。
2. 将招标文件、答疑文件、评分办法和企业资质等资料整理后提供给 Skill。
3. 按 Skill 的工作流生成清单、矩阵或审查报告。
4. 由项目负责人对关键事实、资质有效期、报价和最终文件进行人工确认。

每个 Skill 都是独立目录，入口文件均为 `SKILL.md`，可按需单独使用，也可以按“分析 → 编制 → 审查”的顺序组合使用。

## 🔐 使用边界

- AI 生成内容应以原始招标文件、正式澄清文件和真实企业材料为依据。
- 资格条件、合同条款、报价、承诺事项及法律责任应由企业授权人员最终确认。
- 不上传与项目无关的敏感个人信息、商业秘密或未经授权的第三方材料。
- 本仓库提供的是工作方法与提示规范，不构成法律、财税或采购合规意见。

## 🧪 推荐工作方式

> **先分析，再编制；先核验，再提交。**

建议将每一次投标任务保留“原始文件—分析结果—响应矩阵—审查报告—最终版本”的链路，形成企业自己的可复用知识库。随着项目积累，可进一步沉淀行业模板、常见评分点和证据材料索引。
